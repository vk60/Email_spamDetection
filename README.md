📧 Email Spam Detection App
A simple Machine Learning project that detects whether a message is Spam or Not Spam using:

--------------------------------------------
*Python


*TF-IDF Vectorization


*Logistic Regression


*Streamlit

--------------------------------------------

Detect spam messages instantly

⚙️ Installation
1. Clone Repository
git clone <your-github-repo-link>

2. Move Into Project Folder
cd spam_detection_project

3. Create Virtual Environment
Mac/Linux:
python3 -m venv .venv
Activate:
source .venv/bin/activate

4. Install Dependencies
pip install -r requirements.txt

🧠 Train the Model
Run:
python train.py
This will:


train the ML model


generate:


model.pkl


vectorizer.pkl



--------------------------------------------

▶️ Run the Application
streamlit run app.py

🌐 Open in Browser
Usually opens at:
http://localhost:8501
